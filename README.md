# Site Magno Imóveis Lavras

Site institucional e vitrine de imóveis, construído em HTML, CSS e JavaScript puros.

## Como abrir

Abra `index.html` no navegador. Para desenvolvimento local, também é possível servir a pasta com qualquer servidor HTTP estático.

## Recursos incluídos

- layout responsivo para desktop, tablet e celular;
- busca por finalidade, tipo, bairro e faixa de preço;
- filtros de aluguel e venda;
- cards inteiramente clicáveis, com favoritos salvos no navegador;
- galeria navegável com miniaturas e múltiplas fotos por imóvel;
- modal com endereço, código, características e contato pelo WhatsApp;
- formulário para proprietários com mensagem pronta no WhatsApp;
- navegação móvel, contatos, mapa e SEO local básico.

## Antes da publicação

Os imóveis e valores formam um catálogo demonstrativo inspirado nas referências fornecidas. Substitua-os pelo estoque real em `script.js` e confirme horários, links, CRECI e demais informações oficiais da imobiliária.

## Créditos de imagem

A fotografia principal foi criada especificamente para este projeto com a ferramenta de geração de imagens da OpenAI. As fotografias dos cards são de autores disponibilizados pelo Unsplash e devem permanecer de acordo com os termos da plataforma.
